# 🌟 Portafolio - Andrés López Piña

Portafolio personal desarrollado con Next.js, TypeScript, Tailwind CSS y Framer Motion. Muestra mis proyectos, habilidades y experiencia como desarrollador Full Stack.

## 🚀 Tecnologías Utilizadas

- **Framework**: Next.js 14
- **Lenguaje**: TypeScript
- **Estilos**: Tailwind CSS
- **Animaciones**: Framer Motion
- **Iconos**: Lucide React
- **Deployment**: Vercel

## 🎨 Características

- ✨ Diseño moderno y responsive
- 🎭 Animaciones fluidas con Framer Motion
- 📱 Optimizado para móviles
- 🚀 Rendimiento optimizado
- 🎨 Paleta de colores personalizada
- 🌐 SEO optimizado

## 📋 Secciones

- **Inicio**: Presentación principal
- **Sobre Mí**: Información personal y foto
- **Experiencia**: Resumen de trayectoria profesional
- **Habilidades**: Tecnologías organizadas por categorías
- **Proyectos**: Portfolio de trabajos realizados
- **Contacto**: Información de contacto y formulario

## 🛠️ Instalación y Desarrollo

```bash
# Clonar el repositorio
git clone https://github.com/AndresLP020/CV.git

# Navegar al directorio
cd CV

# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev

# Construir para producción
npm run build

# Iniciar servidor de producción
npm start
```

## 🚀 Deploy en Vercel

Este proyecto está optimizado para deployment en Vercel:

1. Conecta tu repositorio a Vercel
2. Vercel detectará automáticamente que es un proyecto Next.js
3. El deployment se realizará automáticamente
